DUNGEON MASTER'S TOOLKIT — Folder Edition
==========================================
1. Unzip this folder anywhere (keep ALL files together).
2. Open "Dungeon Master's Toolkit.html" in any modern browser.

Everything works fully offline. The resource-map-*.js files carry the
artwork at full quality, spell-db.js / spell-effect.js carry the
spell library, and the assets/ folder holds the party portraits and
campaign comic — the HTML loads them all from this folder, so do not
rename or separate them from the HTML.
