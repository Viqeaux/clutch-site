Drop character profile pictures in this folder.

Name each file to match either the character's first name, or their
full name slug (lowercase, spaces and special characters replaced
with hyphens) — both are checked. For example, either of these works
for Vigeaux the Carcajian:

  vigeaux.png
  vigeaux-the-carcajian.png

Full list (first-name version shown; the full-name slug also works):

  alfie.jpg
  tom-jones.jpg  (or tom.jpg)
  vigeaux.jpg  (or vigeaux-the-carcajian.jpg)
  wyatt.jpg  (or wyatt-smithereen.jpg)
  derder.jpg  (or derder-erder.jpg)
  snivel.jpg  (or snivel-sarcat.jpg)
  willa.jpg
  gary.jpg  (or gary-smithereen.jpg) — currently hidden from the
    gallery since this character is marked "resting" in the sheet
  vohnkar.jpg  (or vohnkar-nelwyn.jpg) — same, hidden while resting

.jpg, .jpeg, .png, and .webp are all supported. If no matching file is
found for a character, the Meet The Clutch page shows a placeholder
sigil instead — nothing breaks.

Note: if this site is ever hosted on a case-sensitive server (GitHub
Pages, Linux, etc. — as opposed to opening it directly from Windows),
filenames must be all-lowercase to match. Capitalized names like
"Vigeaux.png" work fine locally on Windows but would fail there.
